# Visual direction

## Concept

The site combines the atmosphere of an archival furniture catalogue with the responsiveness of a contemporary digital exhibition. The chair remains the constant subject while the representational system changes chapter by chapter.

## Priorities

1. **Editorial clarity:** the seven required objects must be immediately identifiable.
2. **Material warmth:** paper, cream, orange-red, moss, and charcoal reference plywood, print, and mid-century interiors without reproducing a historical style literally.
3. **Large-scale typography:** Instrument Serif creates expressive chapter openings; DM Sans handles reading; DM Mono labels data, controls, and technical context.
4. **Interaction as explanation:** movement should reveal structure or invite investigation, not decorate the page.
5. **Consistent framing:** every visualization uses the same borders, headers, captions, context notes, and metadata language.

## Interface rules

- Use orange to mark sequence, active progress, and important interpretive cues.
- Use one-pixel rules to organize content instead of heavy cards or shadows.
- Keep prose lines narrow enough for comfortable reading.
- Show instructions adjacent to the interaction they describe.
- Use dark chapters only for spatial immersion and the conversational agent.
- Preserve full keyboard access, visible focus, descriptive labels, and reduced-motion support.

## Responsive behavior

Desktop uses asymmetric editorial grids. Below 900px, the chapter navigation becomes a full-screen menu and all context layouts collapse to a single reading column. Data visualizations retain generous minimum heights so their labels remain legible.
