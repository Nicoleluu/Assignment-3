Object 01 / 072D spatial canvas

Learning the chair
by drawing it.

The chair first becomes a set of lines, surfaces, and proportions. Three p5.js studies move from observation to material behavior and assembly.

01A · Observe

A generative line drawing reduces the DCM to its recognizable silhouette.

01B · Bend

Move across the canvas to press flat veneer layers into a curved shell.

01C · Assemble

Add the frame, seat, and back to reveal the logic of the whole.

Context / intent

I used 2D canvas as a method of close looking. Rather than treating the DCM as a finished image, each interaction isolates a design operation—outline, lamination, proportion, and assembly. The studies are drawn in p5.js and reference the chair’s molded-plywood shells and tubular steel frame.

Tools: p5.js · mouse interaction · orthographic drawing

Object 02 / 073D spatial canvas

Form changes
as you move.

A two-dimensional photograph fixes a viewpoint. This WebGL model returns control to the viewer: rotate, zoom, and inspect the relationship between shell and frame.

Live model · GLBDrag to rotate · scroll to zoom

Loading three-dimensional chair…

Context / intent

I built this scene to study spatial relationships that flatten in elevation: the gap between seat and back, the angle of recline, and the lightness of the steel structure. OrbitControls makes inspection non-linear; the viewer decides which detail becomes foreground.

Tools: Three.js · GLTFLoader · OrbitControls · Eames DCM 3D model

Object 03 / 07Temporal structure

A day measured
in occupied time.

Furniture is never truly static. This timeline records one imagined day of use, shifting between work, meals, conversation, rest, and vacancy.

24-hour study

The rhythm of sitting

Hover over an interval to inspect a moment

Context / intent

I translated a synthetic daily-use log into duration, sequence, and recurrence. The goal was to describe the chair through events rather than appearance: occupancy is temporary, but repeated routines give the object a social life.

Tools: D3.js · CSV · synthetic 24-hour use dataset

Object 04 / 07Relational structure

A chair is
a network.

The DCM is not a single form. It is an agreement among materials, fabrication processes, parts, bodies, and patterns of use.

Drag nodes · scroll to zoom

Loading relational network…

13 nodes19 relationshipssynthetic study data
Context / intent

I modeled the chair as connected entities instead of a hierarchy. Force-directed movement makes every category mutually dependent: pulling “plywood,” for example, changes the positions of molding, shell, comfort, and use. The graph turns relationships into a material that can be handled.

Tools: D3 force simulation · CSV node and edge lists

Object 05 / 07Geospatial structure

Designed here.
Made there. Seen everywhere.

The chair’s story crosses the United States: experimentation in California, serial production in Michigan, and cultural preservation in New York.

Material geography · 1946–present

One chair, three situated contexts

Design journeySituated placeBoundaries: PublicaMundi
Context / intent

I mapped three institutions to show how design value is produced across place: an idea begins in a studio, becomes repeatable through manufacturing, and enters a design canon through collection. A local D3 map remains fully functional when the optional Mapbox layer is unavailable.

Tools: Mapbox GL JS + D3 fallback · GeoJSON · PublicaMundi state boundaries

Context / intent

I designed this poll to turn viewing into a small act of authorship. Firebase aggregates only four shared counts; it does not request names, contact details, location, or demographics. A local browser marker discourages repeat votes. Results are exploratory, not representative.

Object 07 / 07Agent

Ask the chair
what to notice.

Seat Guide extends the project through conversation, connecting questions about material, structure, history, and use to details already explored above.

AI design guide · OpenAI + Firebase

What would you like to notice?

Connecting…
Seat Guide

I’m here to help you look more closely at the Eames DCM. Ask about its plywood shell, steel frame, history, or the choices behind its form.

AI responses can be inaccurate. Use them as a starting point for observation.

Context / intent

I prompted the agent as a concise design-education companion rather than an authority. It redirects attention toward close observation and distinguishes fact from interpretation. The API key remains server-side; rate limits and input validation protect the public endpoint, while a disclosed local guide keeps the interaction useful if the cloud service is unavailable.

Tools: OpenAI Responses API · Firebase callable function · session-scoped conversation
